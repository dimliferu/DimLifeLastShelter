# Game graphics assets

Place the separate PNG files for room backgrounds, survivor sprites, and resource icons in this directory. Android will package these resources with the app.

Expected files include `room_reactor.png`, `room_command.png`, `room_living.png`, `room_water.png`, `room_farm.png`, `room_medical.png`, `survivor_engineer.png`, `survivor_medic.png`, `survivor_guard.png`, `survivor_scientist.png`, `survivor_farmer.png`, `survivor_mechanic.png`, `icon_power.png`, `icon_water.png`, `icon_food.png`, and `icon_oxygen.png`.
